## Expression

Storefront se řídí `storefront-expression`. Core ecommerce UI je:

- Paper / White stage;
- Ink text a primary commerce actions;
- warm-gray Tile pro product / category plochy;
- 1px Line borders;
- radius `0` jako výchozí;
- žádné card shadows;
- Anton + Nunito Sans;
- Hot Rose pouze se skutečnou promo / sale / checkout rolí.

## Vizuální priorita

### Product listing

1. produktový obraz;
2. název;
3. cena;
4. velikosti / dostupnost;
5. badge pouze pokud nese reálnou informaci.

Badge nesmí přebít produkt.

### PDP

1. produktová galerie;
2. název produktu;
3. cena a stručná ověřená product facts;
4. varianty — střih, velikost, barva;
5. Add to Cart;
6. doplňky / upsell;
7. detailní parametry, péče, doprava, recenze.

Cena musí být viditelná bez hoveru nebo interakce. Add to Cart musí být jasně dominantní v buy-boxu, ale nemusí být Hot Rose — standard je Ink.

## Product cards

- photo surface: warm-gray Tile;
- bez radiusu a bez stínu;
- produkt může opticky přetékat / být lehce rotovaný, pokud zůstane exact;
- název: Anton uppercase;
- cena: čitelná okamžitě;
- původní cena: Faint + strike-through;
- slevová cena / badge může použít Hot Rose;
- velikosti: malý sekundární Nunito Sans text;
- max 2 badge, v praxi preferuj 0–1.

## Variants and filters

- chips a size cells jsou hranaté;
- default = Paper + Line border + Ink text;
- selected = Ink fill + White text;
- unavailable = světlý neutral + strike-through / disabled treatment;
- selected state nesmí být komunikován pouze barvou.

## CTA

Viz `cta-rules`.

- Add to Cart = Ink primary;
- Checkout = Hot Rose;
- secondary action = underline / arrow link nebo outline;
- žádné dva stejně silné primary buttony vedle sebe.

## Hero

Storefront hero má fungovat jako editorial commerce, ne jako generický reklamní plakát.

- produkt je největší vizuální signál;
- text je krátký;
- jedna akce;
- negativní prostor je funkční součást layoutu;
- background může být Paper, Tile nebo Ink;
- product accent je povolen lokálně podle design/creative-expression;
- pokud je hero uvnitř webu, neduplikuj logo bez důvodu — header už značku nese.

## Mega menu

- bílá / Paper plocha;
- jasné sloupce podle user intent;
- feature product tile může používat warm-gray stage;
- pouze overlay vrstva může mít jemný stín;
- stránka pod menu může být ztmavena scrimem;
- `Výprodej` může nést Hot Rose jako semantický signal.

## Cart

- čitelný line-item layout;
- summary panel může použít Tile;
- běžné edit / remove akce jsou neutrální;
- `Pokračovat k pokladně` = Hot Rose;
- doprava zdarma progress může použít Hot Rose, pokud jde o obchodní progress;
- sklad / error používá semantic colors, ne brand accent.

## Mobile

Mobile není desktop poskládaný pod sebe.

- page X přibližně 18px;
- product listing 2 sloupce;
- dostatečné touch targets;
- category subnav může horizontálně scrollovat;
- PDP může mít sticky Add to Cart;
- hero headline a product crop musí být navrženy samostatně pro 390px class viewport;
- footer může přejít do accordion rows.

## Dark surfaces

Ink / dark surface je povolen pro:

- announcement bar;
- footer;
- campaign / hero block;
- overlay.

Core listing, PDP buy-box, cart line-items a formuláře zůstávají převážně světlé kvůli čitelnosti a product-first scéně.

## Gradienty

Gradienty nejsou součástí canonical storefront jazyka. Pokud campaign art direction výjimečně potřebuje fotografický světelný přechod, musí jít o součást reálné / generované fotografie, ne UI gradient token.

## Do

- navrhuj komponenty nejdřív černobíle;
- nech produkt nést barvu;
- používej Tile místo card shadow;
- invertuj selected state do Ink;
- používej exact product imagery;
- drž mobile-first hierarchy.

## Don't

- nepoužívej pink jako default Add to Cart;
- nezaobluj vše;
- nepřidávej stíny kartám;
- nevkládej product accent do globální UI;
- nevyráběj vizuální hierarchii pomocí pěti barev;
- nevymýšlej product claims nebo availability z designového kontextu.
