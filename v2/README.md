# BU1 Brand & Design v2

Status: **draft / in development**

This directory contains the next-generation BU1 visual system. It is intentionally isolated from the current brand system until v2 is reviewed and approved.

## Working name

**BU1 Editorial Performance System v2**

## North star

BU1 should feel like a premium goalkeeper brand that combines:

- fashion-editorial visual discipline,
- technical product credibility,
- bold condensed typography,
- product-first composition,
- and performance-oriented clarity.

The core visual equation is:

> oversized product + bold condensed typography + negative space + minimal information + technical proof

## v2 principles

1. **The product is the hero.** Product imagery should dominate the composition rather than sit inside a generic layout.
2. **The product is exact.** Never invent, redraw, recolor, or approximate a real BU1 product in final commerce or campaign assets.
3. **The logo is exact.** Use official logo assets only; never regenerate the BU1 logo with AI.
4. **Typography carries the brand voice.** Headlines are short, bold, condensed, editorial, and visually dominant.
5. **Color follows the product.** The product’s own accent color should normally be the main chromatic signal.
6. **Hot Rose is semantic, not decorative.** Use it for labels such as NOVINKA, SALE, DROP, LIMITED, or other meaningful states.
7. **Minimal copy, maximum confidence.** Prefer short claims, one technical proof line, one price, one CTA.
8. **Asymmetry is preferred.** Oversized crops, edge overflow, scale contrast, and deliberate tension are core to the system.
9. **AI is an art-direction tool, not a source of product truth.** Inspiration sources such as Inspia may guide composition, lighting, crop, shot design, motion, or storytelling; production method is decided separately.
10. **The system must scale across channels.** Web, social, PPC, print, packaging, retail, video, and product graphics should feel related without being identical.

## Versioning rule

The existing repository outside `/v2` remains the active v1 system until v2 is explicitly approved and promoted. Do not silently replace v1 rules with v2 assumptions.

## Design direction summary

> **BU1 v2 uses oversized product-led compositions, powerful condensed typography, restrained monochrome layouts and precise technical product detail. The system is premium, editorial and performance-driven. Product color is the main accent. Hot Rose is a small semantic highlight. Every output should feel confident, clean and brand-owned — never generic, noisy or template-like.**
